## Running Locally

1. Clone repository:
```bash
git clone https://github.com/hibbawali/Hibba-portfolio.git
cd Hibba-portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Start development server:
```bash
npm run dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

```bash
npm run build
npm run start
```
