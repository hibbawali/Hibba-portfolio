## 3. Email Spam Classifier

A machine learning project that detects spam messages using TF-IDF
vectorization and compares Logistic Regression and Naive Bayes.

**Dataset:** SMS Spam Collection (Kaggle), 5,572 messages.

**Results** - Naive Bayes: 97.1% accuracy - Precision: 0.99 - Recall:
0.79 - Logistic Regression recall: 0.72

The dataset was imbalanced (87% ham, 13% spam), so accuracy alone was
not enough. Error analysis showed difficulty with adult-content spam
because of vocabulary mismatch.

Users can paste a message into the web interface and receive an instant
spam/ham prediction.

**Tech:** Python, Scikit-learn, Pandas, Flask, TF-IDF Vectorization,
Joblib

**GitHub:** https://github.com/hibbawali/Email-Spam-Classifier\
**Live Demo:** https://spamshield-web.vercel.app/
